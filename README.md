## 静态家宽、动态 NAT、机房 IP，差的到底是哪一层

区别不在带宽，在 IP 的归属记录。

机房 IP 的 ASN 挂在 DigitalOcean、Vultr、OVH 这类托管商名下，IP 数据库标 Hosting 或 Business。动态 NAT 家宽的 IP 来自真实家庭宽带，但每天凌晨换一次，几十个用户共享同一个出口。静态家宽把这两点都反过来：归属是宽带运营商，分配后固定给一个人用。

| 类型 | IP 来源 | 是否固定 | 是否独享 | 月费区间 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| 机房 VPS | 数据中心 ASN | 固定 | 独享 | $3–$30 | 建站、开发、代理 |
| 动态 NAT 家宽 | 真实家庭宽带 | 每日更换 | 共享 | ¥24–¥30 起 | 爬虫、临时测试 |
| 静态家宽 | 宽带运营商住宅段 | 固定 | 独享 | ¥149 起 / $15 起 | 账号运营、直播、AI 服务 |

平台判定时不只看 ASN。IP 的 usage type、历史黑名单记录、同一个 C 段里挂了多少代理，都会被算进去。这也是“住宅 IP”四个字被用滥的原因：改个 rDNS、换个 IP 库标签，看起来都像家宽，一查 ASN 就露馅。

## 拿到机器先别登号：三步验证

**第一步查 ASN。** 在 bgp.he.net 或 ipinfo.io 输入 IP，看归属是不是 Cox Communications 或 AT&T 本体。如果显示的是某家转售商，直接找客服。

**第二步查 usage type。** 在 IP2Location、ipinfo 看标记是 ISP / residential 还是 hosting / datacenter。标记不对，后面所有操作都白做。

**第三步查历史。** 用 Scamalytics 查风险评分，再看有没有被主流黑名单收录。原生住宅 IP 的评分通常在个位数到二十几之间，分数偏高说明这个 IP 之前被人用过。
